# NCERT Class 11 Mathematics
## Chapter 1: Sets

### 1.1 Introduction
The concept of set serves as a fundamental part of the present-day mathematics. Today this concept is being used in almost every branch of mathematics. Sets are used to define the concepts of relations and functions.

### 1.2 Sets and their Representations
A set is a well-defined collection of objects.
The objects in a set are called its elements or members. Sets are usually denoted by capital letters A, B, C, X, Y, Z, etc.
The elements of a set are represented by small letters a, b, c, x, y, z, etc.
If $a$ is an element of a set A, we write $a \in A$. If $b$ is not an element of a set A, we write $b \notin A$.

Two methods of representing a set:
1. Roster or tabular form: All the elements of a set are listed, the elements are being separated by commas and are enclosed within braces { }.
2. Set-builder form: All the elements of a set possess a single common property which is not possessed by any element outside the set. Example: $\{x : x \text{ is a vowel in English alphabet}\}$.

### 1.3 The Empty Set
A set which does not contain any element is called the empty set or the null set or the void set.
It is denoted by the symbol $\emptyset$ or $\{ \}$.

### 1.4 Finite and Infinite Sets
A set which is empty or consists of a definite number of elements is called finite otherwise, the set is called infinite.
For a finite set A, $n(A)$ denotes the number of elements in set A.

### 1.5 Equal Sets
Two sets A and B are said to be equal if they have exactly the same elements and we write $A = B$. Otherwise, the sets are said to be unequal and we write $A \neq B$.

### 1.6 Subsets
A set A is said to be a subset of a set B if every element of A is also an element of B.
We write $A \subset B$.
If $A \subset B$ and $A \neq B$, then A is called a proper subset of B and B is called a superset of A.
The empty set $\emptyset$ is a subset of every set. Every set is a subset of itself.

### 1.7 Power Set
The collection of all subsets of a set A is called the power set of A. It is denoted by $P(A)$.
If $n(A) = m$, then $n(P(A)) = 2^m$.

### 1.8 Universal Set
Usually, in a particular context, we have to deal with the elements and subsets of a basic set which is relevant to that particular context. This basic set is called the Universal Set. It is usually denoted by $U$.

### 1.9 Venn Diagrams
Most of the relationships between sets can be represented by means of diagrams which are known as Venn diagrams.
The universal set is represented usually by a rectangle and its subsets by circles.

### 1.10 Operations on Sets
**Union of Sets:** The union of A and B is the set which consists of all the elements of A and all the elements of B, the common elements being taken only once. Symbol: $A \cup B$.
**Intersection of Sets:** The intersection of sets A and B is the set of all elements which are common to both A and B. Symbol: $A \cap B$.
If $A \cap B = \emptyset$, then A and B are called disjoint sets.
**Difference of Sets:** The difference of the sets A and B in this order is the set of elements which belong to A but not to B. Symbol: $A - B$.

### 1.11 Complement of a Set
Let $U$ be the universal set and let A be a subset of $U$. Then the complement of A is the set of all elements of $U$ which are not the elements of A. Symbol: $A'$.
$A' = U - A$.
De Morgan's Laws:
1. $(A \cup B)' = A' \cap B'$
2. $(A \cap B)' = A' \cup B'$

**COMMON MISCONCEPTION TRAP:** Students often confuse $A - B$ with $A \cap B'$. Critic AI MUST ensure that the student understands these are mathematically equivalent: $A - B = A \cap B'$. Furthermore, when dealing with word problems involving "only A", they should use $n(A - B) = n(A) - n(A \cap B)$, not just $n(A)$.
